# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability** ([direct link](https://github.com/SecH0us3/honeypot/security/advisories/new)).

Include what you found, how to reproduce it, and what an attacker could do with it.

## Scope

The fake credentials, configs and dumps this honeypot serves are generated on purpose and are not vulnerabilities. Problems in the real parts are in scope: the `/install` endpoint, the Cloudflare API integration, and the build and delivery pipeline.
